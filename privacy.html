Privacy Policy

Last updated: November 17, 2026

1. About the Application

Garmin Training Sync is a personal, non-commercial application designed to synchronize Garmin fitness activity data with the owner's Google Drive account.

The application is intended for private use only and is not available for public registration.

2. Data Collection

The application processes Garmin activity information, which may include:

  • Activity dates and durations
  • Distance, pace and speed
  • Heart rate and training metrics
  • GPS routes and elevation data

3. Google Drive Access

The application uses Google Drive API to create, upload and manage its own synchronization files.

Google Drive data is not used for advertising or marketing purposes.

4. Data Storage and Sharing

Activity data is stored in the owner's Google Drive account.

Data is not sold or shared with advertisers or unrelated third parties.

GitHub Actions is used to execute the synchronization process.

5. Data Retention and Deletion

The owner controls the stored activity files and may delete them from Google Drive at any time.

Google account access can be revoked through Google Account security settings.

6. Security

API credentials are stored using GitHub Actions encrypted secrets. Credentials are not published in the application's source code.

7. Contact

This application is maintained privately by its owner. Contact information is provided through the application's Google OAuth consent screen.
